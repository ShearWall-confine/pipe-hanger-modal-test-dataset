# v1.1.0 — 56-condition revision evidence release

This release closes the 55/56 metadata mismatch and publishes the machine-readable evidence supporting the revised manuscript.

## Changes

- Adds the missing `TB_07_A` row to `data/metadata/experiment_index.csv`, bringing the raw-file index to 56 conditions.
- Publishes `modal_db_v1.1.h5` with all 56 conditions.
- Preserves raw signals and stores processed signals separately as optional `signal_adjusted` datasets.
- Adds the 56-condition index and complete 168-row condition--mode decision record.
- Adds signal-provenance, calibration-sensitivity, NLI-window, applicability-domain, damping-lineage, and shared-axial parameter-audit files under `data/metadata/revision_2026/`.
- Extends the validation script to check the raw-file index against the 56 public XLS files.
